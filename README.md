# firmfooting brand

The mark is a footing: a wide, stable base poured first, so what stands on it does not slip.

## Colour

| Token | Value | Use |
|---|---|---|
| Primary | `#2A6B64` | Tile background, headings, links |
| Mark | `#FFFFFF` | The footing glyph on primary |

Dark-mode variants use the same tile, so no dark asset is required.

## Assets

- `logo.svg` — vector source.
- `logo.png` — 256×256 raster, used as the org avatar and in the profile README.

## Rules

- Sentence case everywhere. No title case, no marketing voice.
- Plain words. The brand promise is safety and steadiness; the writing should feel the same.
- The mark sits on a `#2A6B64` tile or on white. Do not tint it.
